# Decisões de documentação

- A publicação verificada pelo fluxo de release fornece evidência para substituir avisos prospectivos por instruções diretas de instalação.
- Os exemplos sem versão usam a versão corrente do registro; os exemplos reproduzíveis fixam `0.1.1` explicitamente.
- O fluxo de distribuição e o capítulo histórico de preparação permanecem em `docs/release-process.md`; remover avisos de disponibilidade não elimina orientações operacionais internas.
- Esta alteração não muda contratos de API, código distribuído, workflows, credenciais ou configurações npm.
