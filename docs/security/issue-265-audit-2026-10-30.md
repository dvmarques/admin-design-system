## Método reproduzível

Em cada revisão, executar na raiz do respectivo worktree:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm audit --json > audit-all.json
npm audit --json --omit=dev > audit-production.json
```

O runner capturou o código de saída de cada audit, verificou que os arquivos eram JSON válidos com `metadata` e `vulnerabilities`, e gerou inventário consolidado. Foram usados o mesmo Node e npm para ambos os lockfiles. O relatório de produção utiliza `--omit=dev`; o inventário `metadata.dependencies` ainda descreve a árvore de dependências do projeto, e não deve ser somado entre categorias, que podem se sobrepor.
